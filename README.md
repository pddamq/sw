# Forma CAD

Vue3 + Python 异步任务循环 + C# SolidWorks MCP 的本地 Windows AI 工作台。
当前版本：1.0.0。

## 1.0.0 源码更新：可恢复的大型工具结果

- 借鉴 DeepSeek Harness 的结果留存机制：大型返回保留完整文本，聊天和模型上下文只显示头尾预览及分页读取标识。
- Agent 可通过只读 `tool_result_read` 找回中间内容，聊天工具记录和任务轨迹也可点击「读取完整结果（分页）」；读取不重放原操作，不改变成功、失败或审批状态。
- 按会话隔离、摘要校验、容量清理及会话删除联动；留存失败时保留原返回并明确提示，过期结果不伪造成功。
- 借鉴来源、容量限制与验证边界见 [DSH 融合说明](docs/DSH_INTEGRATION.md)。本次为源码更新，现有发布包尚未重打包。

## 后续源码更新：Blender 内置与一键使用

- 随应用附带固定版本 Blender MCP、自包含 Python 运行时、匹配插件与纯 Python 依赖，终端用户无需 uv、命令行或 JSON。
- 自动发现已安装的 Blender，一键打开独立窗口、加载随包插件、分配本机端口并读取场景核验后进入建模；既有 Blender 窗口和用户插件配置保持原样。
- 便携版路径支持记住；内置服务随应用目录移动，外部自定义配置保持不变。任务执行期间接入锁定，启动失败不冒充场景就绪。
- 构建流程强制验证并包含 Blender 离线资源。Blender 软件本体仍使用用户本机安装，真机场景验收范围见 [Blender 接入说明](docs/BLENDER_MCP.md)。

- 来源列表只有 1 至 3 个文件但包含大量片段时，也能展开后收起；显示实际片段总数，切换历史任务重置折叠。
- 以上为源码更新，已有 0.9.0 安装包尚未重新生成。使用范围及限制见 [工程闭环说明](docs/ENGINEERING_LOOP.md)。

## 本次修复：批次语义、重复调用与历史记录

- 同批工具调用不再因一条失败而短路；每条调用独立返回 `outcome/executed/category`，多调用批次附成功/失败/未执行汇总。
- 模型猜错工具名不再丢弃整轮回复：未知名称得到 `unregistered_tool` 逐调用结果，同批可能修改 CAD 的已知调用标为 `unavailable_batch` 跳过，避免计划不完整时推进模型。
- 相同参数的失败调用不再被应用直接拦截；状态未变化时照常执行并附加 `repeat_notice` 建议，用户启动 SW 后的真实重试可到达执行器。
- `sw_status.recentOps` 只作为有界窗口展示，显式给出省略数量与 `operationLog`；新增只读 `executor_history` 分页读取追加日志，`vbaEnabled=false` 会补上设置/重连原因。
- 正文工具协议恢复扩展到 JSON 数组、裸 `{name,arguments}`、单数 `<tool_call>`、`<tool_use>`、函数写法和推理通道；提示词不再放置可复制的字面调用信封。
- 详见 [批次、重复调用与历史对齐](docs/BATCH_AND_PROTOCOL_ALIGNMENT.md)。

## 0.8.1 更新：异常停止与证据刷新

- 执行器超时、断连或返回格式异常时，将调用标为结果待核实并结束任务；模型不再接收此异常后自动继续规划。

- 确认提交成功后保持按钮锁定，等待后端状态更新，避免重复提交。


## 0.8.0 更新：操作确认、检查点与验证证据

- 对保存、关闭、撤销、删除、覆盖、接管已有文档、启动 SW 和宏执行等关键调用增加一次性界面确认；确认绑定本任务的具体工具与参数，5 分钟过期，重复或跨任务提交失效。

- MCP 标准客户端：从 C# 服务动态发现工具与 JSON Schema，按任务选择工具；每个 SW 实例串行调用。

- 上下文：SQLite 保存全部消息、工具事件及会话摘要；较长会话通过模型压缩较早消息。
- Windows DPAPI 加密模型密钥；日志、会话及索引在用户目录中保存。
- pywebview 桌面启动器、PyInstaller EXE 配置、Inno Setup 安装包配置。

本项目没有把模拟结果当作 SW 执行。MCP 未连接时不注册 CAD 工具，不产生虚构的 CAD 文件；本地问答卡片和操作历史查询仍可使用。
默认完整工具版包含上游全部 161 个工具，实际工具目录与上游源码逐项比对，不以空壳工具补数量。
保留的 18 工具基础版仅作备选；完整工具版默认允许 Agent 选择 160 项，用户开启 VBA 宏后可选择全部 161 项。
完整 SW 功能覆盖、任意设计成功率、SW2023 全兼容均不是已验收的承诺。
本版支持工具截图展示与参考图片输入，仍未实现实时三维视口。
截图显示仅来自工具返回的真实图片块；测试服务的合成图片不等同于 SW 截图。
图片本身不能证明尺寸、公差、材料或重建状态，仍需工具测量和工程验收。

## 用户第一次使用

1. 安装目标为 Windows 10 22H2 / Windows 11 x64，先确认 SOLIDWORKS 能正常打开。
2. 优先运行完整安装程序；便携版需完整解压后运行 `FormaCAD/FormaCAD.exe`。
3. 应用自动连接随包执行器，安装包已包含 Python 依赖与 .NET 10 运行时，无需开发环境或连接器路径配置。
4. 首次填写模型 API 地址、模型名与 Key。若先打开工作台后启动 SW，点击刷新状态即可重新附加。
5. 缺少 WebView2 时，安装向导或便携版首次启动会请求确认，随后通过 Microsoft 官方引导程序联网补装；离线或企业策略限制时仍需处理安装条件。.NET Framework 4.8 缺失时提示通过 Windows 更新修复，不自动更改该系统组件。

## AI 服务协议

在「模型服务 → 添加/编辑服务 → 连接信息」的「API 协议」下拉框中选择协议。每个服务独立保存；旧配置默认使用 Chat Completions。

- **Chat Completions**：Base URL 例如 `https://api.openai.com/v1`，请求路径追加 `/chat/completions`。
- **Responses**：Base URL 例如 `https://api.openai.com/v1`，请求路径追加 `/responses`。
- **Claude Messages**：Base URL 例如 `https://api.anthropic.com`，请求路径为 `/v1/messages`；地址已经以 `/v1` 结束时不会重复追加。DeepSeek 的 Messages 兼容入口可填写 `https://api.deepseek.com/anthropic`。

勾选「使用完整请求路径」时，原样使用填写的地址。切换协议保留手填地址，请同步检查地址预览。模型列表、连接测试、实际对话和上下文摘要都会使用所选协议；测试包含工具调用及结果回传两轮验证，不操作 CAD。Messages 使用 `x-api-key` 和 `anthropic-version`，其他两种协议使用 Bearer Token。

协议兼容不代表所有模型支持相同的图片、思考强度或工具选项；请按服务的实际能力选择。模型目录接口缺失时可手动添加模型 ID。Embedding 仍使用单独的 OpenAI 兼容向量接口，使用 Messages 服务时应显式配置对应的 Embedding Base URL。

## 首次接入与配置恢复

- 没有历史对话且连接尚未就绪时，工作台自动打开“接入检查”，也可从侧栏随时进入。
- 扫描范围：内置 `resources/builtin-mcp`、可选上游 `resources/mcp`、程序旁 `mcp`、`%LOCALAPPDATA%/solidworks-mcp/bin` 的最多 32 个版本子目录，以及 PATH。
- 发现文件只代表静态检测；“使用此执行器”仅保存配置。自动连接仅限当前应用自带的准确路径，外部程序始终由用户点击连接启动。
- 自包含 EXE 与依赖 dotnet 的 DLL 分开显示。运行时比对采用保守静态检查，实际连接仍是最终依据。
- .NET Framework 4.8 用于桌面外壳和内置基础执行器；.NET 10 运行时/SDK 仅针对可选上游执行器。
- 只读检查 SW COM 注册、已知安装目录和 interop 文件，不自动启动 SW，不自动下载安装软件。
- “导出诊断报告”包含本机路径和依赖信息，不包含模型 API Key 或已加密密钥值。
- `settings.bak` 保留上次保存的配置；损坏主配置不会在启动时被覆盖。

- 配置备份可能包含由 Windows 用户加密的旧密钥，请与主配置一样妥善保管。
- 跨用户迁移导致旧密钥解密失败时，界面提示重新填写，其他有效设置仍可使用。

## SW2023 验收边界

## 知识库与上下文

- 支持 TXT、MD、HTML、文本型 PDF；最大 20MB/文件、500页/PDF。
- 默认 BM25 中英文词法检索，无需下载模型。
- 配置 Embedding 模型和地址后，再导入文档以建立向量。Embedding 使用同一 API Key。
- 更换 Embedding 地址或模型后，旧向量不混用；需要删除并重新导入文档，词法检索仍可使用。
- 当前版本不做 OCR，扫描型 PDF 请先转成可搜索文字。
- 大型企业知识库暂不适合一次导入大量资料；当前索引查询在本机内存中计算。
- 提示词文件在 `backend/prompts/system.txt`。
- 原始会话始终保留；摘要只是给模型的有界上下文，不替代真实 SW 状态。
- `discover_tools` 用中英文关键词发现工具，向模型动态提供部分 Schema，避免一次加载全部工具。
- 每次任务最多 18 轮工具推理、48 次工具调用；到达上限后报告部分进度。
- 在知识库页使用“检索预览”检查命中内容。向量服务失败会回退 BM25，并明确提示实际模式。
- 执行面板的“历史任务”可查看每轮状态与工具记录；对话标题旁的下载按钮导出 JSON。
- 重启后只标记已经退出进程遗留的任务为意外中断，不自动恢复或重复执行建模步骤。

## 图片输入与截图

- 聊天输入框支持拖放附件，也可点击右下角附件按钮。支持 PNG/JPEG/WebP、TXT/MD/HTML/文本型 PDF/CSV/JSON/LOG/XML/YAML，每轮最多 4 个、单个最大 8 MB；文档文字最多 24,000 字符。文档仅随当前会话保存，不自动导入知识库。
- 后端按文件内容验证图片，拒收 SVG、动图及损坏文件；最大 2000 万像素，长边缩放至 1600 像素。
- 保存前转为 PNG 并移除 EXIF、注释及色彩配置等元数据。原图不会原样归档。
- 模型设置中的“启用视觉输入”默认关闭。开启前确认模型支持 OpenAI Chat Completions `image_url`。
- 参考图片会发给所配置的模型服务；MCP 截图在视觉开启时也可用于下一轮分析。
- 最近最多 3 条带图消息参与视觉上下文；单次请求最多保留 8 张图片、base64 总长度约 24 MiB，旧图仍在本地记录中。
- 工具图片在当前所选任务的消息下方展示，可点击放大；视觉关闭仍能显示，但模型不会收到图片像素。
- 没有真实 MCP 返回图片时不生成虚构的 CAD 截图；单张工具图片处理失败会提示，不改变原工具结果。
- 图片通过携带本机令牌的 API 读取，令牌不放在图片 URL 中。
- 删除未发送参考图只移除该附件；已归档图片随会话删除。导出 JSON 包含媒体元信息，不内嵌图片字节。
- 桌面外壳启用下载支持，支持 JSON 导出保存。

## 停止与恢复

停止会终止后续 AI 步骤，但不会撤销已经完成的特征。
已发给 SW 的 COM 调用可能继续执行；后端会等待当前 MCP 调用结束再释放任务锁。
超时不等于操作失败，应先核实 SW 的真实状态；上游版可查询 recentOps（有界窗口）或只读工具 `executor_history` 分页读取 `executor/operations.jsonl` 持久操作日志，内置版使用 feature_list/model_info 与 SW 窗口检查。
每个桌面进程最多一个任务。基础版只在自身进程串行执行；完整上游版另有跨进程 SW 调用序列化，但各应用不共享设计意图，请只用一个工作台控制同一 SW。

- 服务退出时先等待当前 CAD 调用收尾；长仿真最多按工具时限等待。关闭窗口不代表撤销正在运行的 SW 操作。

安装器按当前用户安装，不打包 SOLIDWORKS；缺少 WebView2 时经确认运行随包 Microsoft 官方引导程序，联网下载运行时，完成后重新检查。静默安装缺依赖时默认退出，显式 `/INSTALLWEBVIEW2=1` 才允许联网安装。
pywebview 桌面窗口依赖 Windows .NET Framework 4.8 和 WebView2。
EXE 同目录的 `FormaCAD.exe.config` 是桌面 CLR 配置，分发时与其他依赖一并保留。
发布给外部用户前，完成真机验收、依赖许可证归档和代码签名。当前没有自动更新器。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## 桌面依赖与无窗口诊断

WebView2 完整运行时未直接内嵌，随包的是经 Microsoft 签名验证的联网安装引导程序。若目标电脑已装 WebView2，不会重复执行安装。
确认安装后，便携启动最多等待 10 分钟并复查注册表；非零返回码、重启或网络失败均有明确提示，不把安装进程退出当作就绪。
构建机只下载和验签引导程序，不安装/卸载本机 WebView2。真实缺依赖机器的安装、企业策略和网络差异仍需验收。

安装后开始菜单中的 `Forma CAD Startup Check` 可在桌面窗口打不开时输出本机环境报告；也可运行：

```powershell
.\FormaCAD.exe --check-runtime "C:\Users\[用户名]\Desktop\forma-startup.json"
```

此检查不需要 WebView2，不连接模型，不启动连接器或 SW，不运行安装程序。报告包含本机路径/依赖信息，不含 API Key。
接入检查页可“一键恢复内置连接”，仅改执行器配置，模型服务和密钥保持不变。自动迁移仅针对带随包标记的配置；外部命令和自定义参数不会被强行替换。

## 本地数据

默认 `%LOCALAPPDATA%\FormaCAD`：

- `forma.db`：会话、工具事件、知识库和向量。
- `settings.json`：设置，API Key 用当前 Windows 用户 DPAPI 加密。
- `forma.log`：滚动应用日志。
- `mcp-stderr.log`：C# MCP 标准错误日志。

运行时可以使用 `FORMA_DATA_DIR` 指定独立数据目录。开发可使用 `FORMA_API_KEY` 临时注入密钥；
不写入前端构建、源码或安装包。`FORMA_TOKEN` 仅供测试/开发固定本机访问令牌。
卸载默认保留用户数据；迁移加密密钥到不同 Windows 用户后需要重新填写密钥。

相关设计内容和工具结果会发送到用户配置的模型 API；本地保存不等于离线推理。
