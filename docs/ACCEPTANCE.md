# 真机验收清单

本清单中的项目必须在目标电脑中实际执行后才算通过。自动测试及前端构建不代替 CAD 验收。

## 完整工具版与基础备选

0.6.0 默认交付完整上游 161 个工具；协议目录和 Schema 已验证，真实 CAD 操作仍需逐项验收。
以下完整清单适用于完整执行器，仿真和特征识别需本机对应模块及实际许可。
VBA 宏仅在用户明确打开设置并重连后测试，不把“目录包含”当作已启用或已执行。
18 工具基础备选按 `docs/BUILTIN_EXECUTOR.md` 的矩形板/圆柱流程独立验收。
完整构建的公开 Simulation 引用有 3 个较新 API 的真实 COM 分派适配，按 `docs/FULL_EXECUTOR.md` 单独核实版本与数值。

## 环境与版本

- 记录 Windows、SOLIDWORKS 年份/SP、MCP 提交、模型 ID、.NET 发布版本。
- 执行环境诊断，确认用户安装目录、模板和材料库可用。
- 测试标准用户运行及中文/带空格路径安装。
- C# 服务成功编译并自包含发布，保留全套依赖文件。
- 每一个目标 SW 版本单独验收；优先记录 SW2023 的具体不支持工具。

## 基础闭环

1. 启动 SW，工作台连接 MCP，状态报告真实 SW revision。
2. 新建零件，在合适基准面创建 100mm x 60mm 矩形并拉伸 10mm。
3. 重建，读取体积，理论值为 60000 mm³（未打孔/倒角的矩形板）。
4. 添加 4 个贯穿圆孔，孔径 6mm，孔中心距相邻两边均为 10mm。
5. 重新读取尺寸和体积；理论减少量为 4*pi*3²*10 mm³。
6. 保存原生 SLDPRT 并导出 STEP，实际重新打开文件验证几何。
7. 在用户确认的情况下修改已有零件厚度为 12mm，重建并检查孔保持贯穿。
8. 检查 UI 显示的路径、工具结果与磁盘实际产物一致。

## 0.8.1 异常停止补充验收

- 在可丢弃的测试零件上验证执行器异常断连：任务结束，调用结果保持待核实，后续工具与模型规划停止。
- 修改工具返回后使现场状态读取失败：报告保留该返回，任务失败，后续修改未执行；先核实真实模型再恢复。
- 确认期间切换文档及修改文档状态，检查旧确认失效；超过截止时间的确认提交被拦截。
- 切换历史任务并反复刷新证据，旧请求结果不覆盖新任务；读取失败可重试，截断证据明确提示。
- 这些故障注入仅在测试副本上执行；自动测试不证明真实 COM 调用已撤销。

## 故障恢复

- 不启动 SW，连接后显示真实离线状态而非成功建模。
- 使用错误 MCP 路径，提供可定位错误，界面继续可用。
- 使用错误模型密钥/URL，任务结束后释放锁。
- 任务中点击停止，后续步骤停止；已执行特征不被虚构撤销。
- COM 超时后核对 recentOps 与模型，再继续，不重复创建特征。
- 关闭对话窗口后，Python 服务和自有 MCP 子进程退出；不要结束用户的 SW 进程。
- 模态对话框出现时提示用户处理；丢弃修改或覆盖文件需用户明确确认。

## 后续领域

装配配合/干涉、工程图视图与尺寸、钣金展开、曲面、焊件、仿真等分别建立最小算例，
保存输入、工具事件、实际文件和人工复核结论；以单个工具/工作流为单位标注兼容情况。

## 图片与视觉验收

- 上传参考图后缩略图可见，点击放大和 Escape 关闭正常；刷新后待发送附件仍可见。
- 关闭视觉输入时，带参考图的任务提示配置；普通文字任务仍可执行。
- 开启视觉后，确认所选真实模型能接收 image_url，不把本地协议测试当作模型能力认证。
- 真实 SW 文档调用 view_screenshot 后，画廊图片与实际模型一致，刷新和切换历史任务后仍可读取。
- 关闭视觉时，工具截图仍能展示；模型回复应说明仅有文字结果，不宣称已查看像素。
- 图片不能替代尺寸测量：核对尺寸、孔位、公差仍调用相应测量/检查工具。
- 未携带本机令牌的媒体请求返回 401；跨会话附件提交失败且不产生任务或多余消息。
- SVG、损坏图片、动图、超限图片被明确提示；删除会话后关联图片不再可读取。
- 便携包图片接口验收脚本：`scripts/smoke_media.py`；真实 C# 截图验收需要目标机器。

## 操作确认、检查点与恢复（0.8.0）

- 保存/关闭/撤销/删除/覆盖/接管文档/启动 SW/宏执行触发具体参数确认卡片；点击取消或等待超时，目标操作及后续步骤都不执行。
- 等待确认时切换文档、配置或修改文档 dirty 状态，再确认应停止操作并要求核对；元数据相同的几何变化不在本检查保证范围内。
- 重复提交、旧任务确认、未带令牌及已停止任务确认均失效。
- 工具执行中取消后，检查点保留不确定状态；验证实际模型，确认界面从未声称已回滚。
- 重启后保留历史检查点，选择中断任务只能先核对现场；未保存文档或无记录时显示未知。
- “只读核对并生成续作计划”不执行建模、保存、启动 SW 或宏；新一轮明确指令才进入修改流程。
- 证据面板核对重建/测量/检查/实际保存返回，错误及截断结果清楚可辨；缺少证据不显示验收通过。
- `scripts/smoke_execution.py` 使用本地模型协议测试服务，真实执行器只读 sw_status，取消保存，不代表真机 CAD 验收。

## 分发

- 在未装 Python/Node/.NET SDK 的第二台 Windows 电脑测试完整安装包。
- 分别测试 WebView2 已安装及缺失的行为：已装不重复安装；缺失时确认/取消、离线失败、网络代理、企业策略、重启提示和安装后重检。
- 静默缺依赖安装仅在显式 `/INSTALLWEBVIEW2=1` 时联网；不传时应给出明确错误。
- 修改随包引导程序或校验文件后，应停止补装而不是执行未校验文件。
- 便携版依赖安装发生在后台服务启动之前；取消时不留下本地 API/MCP 子进程。
- 开始菜单 Startup Check 或 `--check-runtime` 可在 WebView2 缺失时保存报告，且没有 API Key、SW/连接器/安装进程。
- 保留旧便携目录，启动新目录：带随包标记的设置应跟随新位置；外部命令及参数保留。
- 安装、启动、重启、升级和卸载符合预期，原有会话和设置保留。
- 模型密钥不出现在前端响应、前端资源、安装包和任务错误中。
- 保留第三方许可证、版本清单，并在正式发布前对安装程序和自有 EXE 签名。
