## 本轮改进

- 任务状态持久化：执行中、停止中、本轮结束、失败、已停止、意外中断。
- 每轮任务有独立 ID；事件按任务分组，历史任务可在执行面板切换。
- 停止请求幂等：连续点击停止、流连接关闭不会重复打断正在收尾的 MCP 调用。
- 即使 MCP 调用收到多次取消，仍等待当前操作返回后再释放执行锁。
- 下次启动时，将所属进程已退出的未完成任务标为意外中断；不自动重放操作。
- 对话与任务记录可以导出为 JSON；导出不包含模型配置或 API Key。
- 知识库增加检索预览，显示实际使用的 BM25 / 混合模式及引用片段。
- Embedding 服务异常时保留关键词检索结果，向用户提示降级，而不是清空全部检索结果。
- 检查向量维度与有限数值；PDF/文字提取在线程中执行，减少界面请求阻塞。
- MCP 连接前检查启动程序、工作目录；提示配置变更后需要重新连接。
- 区分“已连接 MCP”和“已连接 SOLIDWORKS”；诊断中增加执行器路径检查。
- 旧数据库自动新增任务表及事件关联列，保留已有对话和知识库。
- 开发/打包脚本将临时文件放入 build/temp；测试临时目录集中在 build/test-temp。

## 保持明确的边界

- “本轮结束”指 AI 对话/工具流程结束，不代表工程模型已通过验收。
- 任务取消后已经生成的特征保留；中断后先核实 SW 的真实状态再继续。
- 当前仍为应用预览，需要外部已编译 C# MCP；完整打包脚本仍要求构建机有 .NET 10 和 SW SDK。
- SW2023 真机兼容性尚未认证。
